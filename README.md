# Ochre Signal

Australian-owned cyber and managed services landing. Dark ground, Pilbara ochre signal. Light-custom: logo, colours, fonts, copy, and section on/off. Demo copy is generic.

Live demo: https://ochre.little.website/

## Features

- Australian-owned cyber and managed services landing
- Light-custom: logo, colours, fonts, and copy
- Section on/off for hero, capability, services, pathway, assurance, and contact
- Dark ground with Pilbara ochre signal
- Generic demo copy
- Fully responsive Astro SSG

## Design

Typography:
- display: Public Sans

Colors:
- Ground: #1a1410
- Pilbara ochre: #c45c26
- Paper: #f4ebe0

## Customization

Light-custom: logo, colours, fonts, copy, and section on/off.

Edit src/data/site.ts and CSS variables in src/styles.

- Hero
- Capability
- Services
- Pathway
- Assurance
- Contact

Use cases:
- Managed security providers
- Cyber consultancies
- Sovereign MSPs
- Regional security firms
